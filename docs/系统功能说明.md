# 企业接口巡检与稳定性监控系统 - 功能说明

## 一、系统架构

```
day_20/
├── backend/                    # 后端（FastAPI + SQLAlchemy + SQLite）
│   ├── app/
│   │   ├── main.py             # 应用入口：启动调度器、注册路由
```

## 二、系统功能模块

### 功能 1：用户认证与权限管理

| 功能点 | 描述 |
|--------|------|
| 登录 | 用户名 + 密码登录，返回 JWT Token |
| 角色权限 | admin（管理员）、operator（运维）、viewer（观察者）三种角色 |
| 用户管理 | admin 可增删改用户，设置角色/启用状态 |
| 接口授权 | admin 可将指定接口授权给 operator 用户（接口管理页操作） |
| 用户授权查看 | admin 点击用户管理中的用户，跳转查看该用户拥有的授权接口列表 |
| 授权批量删除 | 在用户授权接口列表中可单选或批量删除授权 |

#### 后端代码块

- **认证路由** - `backend/app/features/auth/routes.py`
  - `POST /api/auth/login` → 登录接口
  - `GET /api/auth/me` → 获取当前用户信息
  - `GET /api/users` → 用户列表（admin）
  - `POST /api/users` → 新增用户（admin）
  - `PUT /api/users/{user_id}` → 编辑用户（admin）
  - `DELETE /api/users/{user_id}` → 删除用户（admin）

- **授权路由** - `backend/app/features/apis/routes.py`
  - `GET /api/apis/authorizations` → 获取所有接口的授权信息（admin）
  - `PUT /api/apis/{api_id}/authorizations` → 设置接口授权用户列表（admin）
  - `GET /api/users/{user_id}/authorized-apis` → 获取指定用户的授权接口列表（admin）
  - `POST /api/authorizations/batch-delete` → 批量删除授权记录（admin）

- **认证服务** - `backend/app/features/auth/service.py`
  - `authenticate()` → 校验用户名密码
  - `login()` → 生成 JWT Token
  - `create_user()` → 创建用户（密码自动 bcrypt 哈希）
  - `update_user()` → 更新用户信息
  - `delete_user()` → 删除用户

- **安全/依赖注入** - `backend/app/core/security.py`、`backend/app/core/deps.py`
  - `create_access_token()` → 生成 JWT
  - `verify_token()` → 校验 JWT
  - `get_current_user()` → 获取当前登录用户
  - `require_role()` → 角色权限校验

- **数据模型** - `backend/app/models/models.py`
  - `User` 表 → 用户信息，含角色字段
  - `ApiAuthorization` 表 → 接口授权关联表（api_id/user_id）

#### 前端代码块

- **登录页** - `frontend/src/features/auth/Login.tsx` → 登录表单
- **认证守卫** - `frontend/src/shared/AuthGuard.tsx` → 无 Token 时跳转登录页
- **用户管理页** - `frontend/src/features/users/UserManage.tsx` → 用户 CRUD 界面 + 点击用户跳转到授权接口列表
- **用户授权接口页** - `frontend/src/features/users/UserAuthApis.tsx` → 查看/删除用户授权接口
- **认证状态** - `frontend/src/features/auth/store.ts` → Token/用户信息状态管理
- **API 封装** - `frontend/src/features/auth/api.ts` → 登录/用户管理接口调用

### 功能 2：接口管理 CRUD

| 功能点 | 描述 |
|--------|------|
| 新增接口 | 填写名称、URL、方法、请求头/体、超时、期望状态码等 |
| 编辑接口 | 部分更新接口配置 |
| 删除接口 | 删除接口及关联的日志、告警、统计（级联删除） |
| 复制接口 | 基于现有接口创建副本 |
| 批量操作 | 批量设置巡检间隔、批量启用/禁用、批量删除 |
| 启用/禁用 | 切换接口启用状态，禁用的接口不参与定时巡检 |
| 接口筛选 | 按名称搜索、分组筛选、标签筛选、健康状态筛选 |

#### 后端代码块

- **接口管理路由** - `backend/app/features/apis/routes.py`
  - `GET /api/apis` → 接口列表（支持筛选/分页/健康状态，operator 仅看到被授权的接口）
  - `POST /api/apis` → 新增接口
  - `PUT /api/apis/{api_id}` → 编辑接口
  - `DELETE /api/apis/{api_id}` → 删除接口
  - `POST /api/apis/{api_id}/check` → 手动巡检
  - `PUT /api/apis/{api_id}/authorizations` → 设置接口授权用户
  - `POST /api/apis/batch` → 批量导入
  - `PUT /api/apis/batch/check-interval` → 批量设置巡检间隔
  - `PUT /api/apis/batch/enabled` → 批量启用/禁用
  - `POST /api/apis/batch/delete` → 批量删除
  - `GET /api/apis/authorizations` → 获取所有接口授权信息

- **数据模型** - `backend/app/models/models.py`
  - `Api` 表 → 接口配置全字段

#### 前端代码块

- **接口管理页** - `frontend/src/features/apis/ApiList.tsx` → 接口列表 + CRUD 抽屉表单 + 批量操作
- **API 封装** - `frontend/src/features/apis/api.ts` → 所有接口管理 API 调用

### 功能 4：定时巡检

| 功能点 | 描述 |
|--------|------|
| 定时全量巡检 | APScheduler 每 60 秒触发一次，遍历所有启用接口 |
| 间隔跳跃 | 距上次巡检时间 < check_interval 的接口跳过本次巡检 |
| 手动巡检 | 管理员可对单个接口手动触发巡检（支持自定义请求参数） |
| 自定义测试 | 在编辑接口时可临时修改 URL/方法/请求体等进行测试 |

#### 后端代码块

- **巡检调度** - `backend/app/main.py`
  - `scheduler.add_job(scheduled_check, IntervalTrigger(seconds=60))` → 每 60 秒执行

- **巡检服务** - `backend/app/features/apis/service.py`
  - `check_api()` → 单接口巡检核心方法：使用 httpx.AsyncClient 发送 HTTP 请求，支持 3 次重试，记录响应时间/状态码/响应体大小等
  - `custom_check_api()` → 手动测试用，参数可覆盖接口配置
  - `check_all()` → 全量巡检所有启用接口

#### 路由

- `POST /api/apis/{api_id}/check` → 手动触发巡检路由

### 功能 6：告警管理

| 功能点 | 描述 |
|--------|------|
| 自动告警 | 三种告警类型：响应超时、状态码异常、连续失败 |
| 告警聚合 | 同类型未解决的告警不重复创建 |
| 自动恢复 | 接口从故障恢复到正常时，自动解决告警并发送通知 |
| 手动解决 | 管理员/运维可手动确认解决告警 |
| 告警升级 | 持续 2 小时未解决的告警自动升级通知 |
| 告警筛选 | 按状态、类型、接口筛选告警 |
| 邮件通知 | 新告警和告警解决时发送邮件给相关用户（需配置 SMTP） |
| 视图控制 | viewer 只查看不操作（无"解决"按钮） |

#### 后端代码块

- **告警路由** - `backend/app/features/alerts/routes.py`
  - `GET /api/alerts` → 告警列表（支持筛选/分页）
  - `POST /api/alerts/{alert_id}/resolve` → 解决告警

- **告警服务** - `backend/app/features/alerts/service.py`
  - `check_and_alert()` → 巡检后检测是否触发告警
  - `_check_alerts()` → 检测三种告警类型（超时/状态码/连续失败）
  - `_check_recovery()` → 检测恢复通知，自动解决告警
  - `check_escalation()` → 告警升级检测
  - `get_alerts()` → 分页查询告警（operator 过滤授权接口）
  - `resolve_alert()` → 手动解决告警

- **邮件通知** - `backend/app/core/email_notifier.py`
  - `_send_email()` → SMTP 发送邮件
  - `_get_notify_users()` → 获取通知用户列表（admin + 被授权 operator）
  - `notify_alert()` → 发送新告警通知
  - `notify_resolve()` → 发送告警解决通知

- **邮件配置** - `backend/app/core/config.py` → SMTP_HOST/PORT/USER/PASSWORD/FROM
- **env 文件** - `backend/.env` → SMTP 配置值

- **数据模型** - `backend/app/models/models.py`
  - `Alert` 表 → 告警记录，含 alert_type、status、message 等

#### 前端代码块

- **告警管理页** - `frontend/src/features/alerts/AlertList.tsx` → 告警列表 + 筛选 + 解决操作
- **通知铃铛** - `frontend/src/shared/NotificationBell.tsx` → 头部待处理告警计数 + 音效
- **音效工具** - `frontend/src/shared/sound.ts` → 告警提示音开关
- **告警状态** - `frontend/src/features/alerts/store.ts` → 待处理告警计数状态

### 功能 7：仪表盘

| 功能点 | 描述 |
|--------|------|
| 概览统计 | 总接口数、健康/警告/故障/禁用分布 |
| 今日巡检 | 当日总巡检次数、失败次数 |
| 待处理告警 | 实时显示待处理告警数量 |
| 健康状态分布 | 饼图展示接口健康状态分布 |
| 最近巡检日志 | 最近 5 条巡检记录 |
| 排行榜 | 最慢接口 TOP 10、最不稳定接口 TOP 10（折线图） |
| 点击跳转 | 饼图点击标签跳转到对应筛选后的接口列表 |

#### 后端代码块

- **仪表盘数据** - `backend/app/features/stats/routes.py`
  - `GET /api/dashboard` → 仪表盘概览数据

- **统计服务** - `backend/app/features/stats/service.py`
  - `get_dashboard()` → 仪表盘数据：总接口数、健康分布、今日巡检、待处理告警、最近日志（operator 过滤授权接口）

- **排行榜** - `backend/app/features/stats/routes.py`
  - `GET /api/top-slow` → 最慢接口 TOP N
  - `GET /api/top-unstable` → 最不稳定接口 TOP N

- **接口状态判定** - `backend/app/features/apis/service.py`
  - `get_api_status()` → 根据最近日志判定接口健康状态（success→healthy / failure→down / 无日志→unknown，不含 warning）

#### 前端代码块

- **仪表盘页** - `frontend/src/features/dashboard/Dashboard.tsx` → 统计卡片 + ECharts 饼图/折线图 + 最近日志
- **API 封装** - `frontend/src/features/stats/api.ts` → 仪表盘/排行榜接口调用
